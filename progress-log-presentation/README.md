# Progress Log · bản trình chiếu

Mở `index.html` qua HTTPS dưới thư mục `progress-log-presentation/` trên GitHub Pages. Bài trình chiếu đi qua trải nghiệm giảng viên và học viên trước, rồi kết thúc với hai cách soạn bài. Nhấn **Enter**, **→** hoặc **PgDn** để tiến, **←** hoặc **PgUp** để lùi. **Home** về đầu, **P** mở ghi chú riêng.

Ba trang trình chiếu và cửa sổ ghi chú dùng dữ liệu tự tạo. Màn giảng viên, phiếu và hành trình dùng tài nguyên đã có của Progress Log tại `progress-log/releases/e75677d3c052cde5/`. Kết quả nhập câu hỏi bằng AI đã được chuẩn bị trong dữ liệu trình chiếu. Trình duyệt chặn kết nối API từ các trang này, và mỗi phiên có bộ nhớ riêng. Các gói đã phát hành của sản phẩm nằm ngoài thư mục này.
