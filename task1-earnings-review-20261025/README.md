# Earnings — bản thử giao diện SW Task 1

Chỉ route này nhận UI mới; không thay route handout đang dùng. Nguồn/cascade được ghim trong source-lock.json. API là `/task1-preview-api/`, database và dữ liệu thử riêng đã có; không ghi vào `/writing-api/` hoặc backend Task 2.

Học viên: `index.html?class=TASK1-THU-A`. Giảng viên: `teacher.html?class=TASK1-THU-A`. Chọn Học viên thử để luyện; lịch sử các lớp cũ trên dashboard là bản sao chỉ đọc. Ghi nhớ ở bản thử dùng namespace riêng, không thay danh tính ERP đã nhớ trên bài thật.

Giữ năm ô/ba chặng, Outline gửi chung và cho ít nhất một Body có chữ, Draft chỉ mở sau Overview/Outline đạt; học viên tự viết Overview + Body 1, copy sang Draft 2 rồi tự sửa. Phần đã đạt khóa, giảng viên có quyền mở lại kèm lý do. Phản hồi Socratic mới và LMS lịch sử có renderer theo nguồn; không điền câu sửa vào bài.

Test hẹp: `npm test` tại thư mục này. Test hồi quy controller gốc: `npm test` trong writing-handouts. Kiểm UI, Google, AI và dữ liệu VPS có biên nhận riêng; source/unit test không tự chứng minh bản HTTPS đã được nghiệm thu. Chưa chuyển lớp thật trước khi Đức chốt.
