# HTTPS thử riêng cho cache phiên giảng viên

Chỉ thư mục này được phát hành để kiểm theo quyền Đức ngày 23/10/2026. Không đổi thư viện hoặc trang sản phẩm thật. Hai bản gốc/tối ưu có prefix API, cookie và database thử riêng.

Google được xác minh bằng chữ ký/audience thật. Hai phiên bản dùng đúng source broker/consumer đã ghim, chỉ đổi namespace cookie/path trong gói thử. Term dùng HTTPS 18869. Không chặn mạng API, cài cookie hoặc giả Google ở phép nghiệm thu HTTPS.

Khu thử kiểm hợp đồng đăng nhập giữa mười adapter; đây không phải bản sao toàn bộ ứng dụng. SQL/session gốc dùng cho native adapter; Mapping dùng auth module đã ghim; Handout/Substitute dùng mã kiểm quyền gốc với registry/roster/grant mẫu. Các route Reading/Listening/Materials chỉ kiểm native session và lớp mẫu, không thay nghiệm thu toàn bộ nghiệp vụ ở API sản phẩm thật. Không có đường nộp/chấm/AI/Portal. Hạn phiên thật được đọc tổng hợp trên runtime riêng; các mốc 90/365 ngày kiểm bằng clock trong đúng image thay vì đợi thời gian thực.

Số liệu UI chỉ chứa đường API thử, phương thức, HTTP và thời gian; không ghi cookie, Google credential, nội dung request hoặc danh tính. Mở trang đo tạo iframe mới cùng origin để đo lần mở phiên đầu, không tự đăng nhập hoặc giả phiên trong iframe. Google cần được đăng nhập ở cả hai bản trước khi so phiên có sẵn.

Production và lớp thật chưa được phát hành bởi gói này. Browser fixture kiểm màn ở 1440/390 trước publish chỉ là kiểm UI, được ghi riêng với Google thật/HTTPS.
