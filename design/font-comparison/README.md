# So sánh font trên bảng màu Reading

Demo độc lập: cùng nội dung, màu, cỡ chữ, độ đậm, giãn dòng và bề rộng; chỉ đổi Nunito Sans, Geologica hoặc Inter. Hai chế độ so cạnh nhau/xem rộng, ba ngữ cảnh học viên/đọc dài/bảng và biểu mẫu. Nội dung và tên học viên đều giả lập.

Nút thử và ô nhập chỉ thay đổi bộ nhớ trang; tải lại sẽ xóa nội dung gõ thử. Tham số URL giữ cách xem, ngữ cảnh, font và mức phóng chữ; mỗi tab độc lập. Không gọi API học tập, không áp lựa chọn lên sản phẩm khác.

Font WOFF2 biến thiên 400–700, bộ ký tự Latin và tiếng Việt, được tải từ [Google Fonts](https://fonts.google.com/) ngày 22/10/2026. Giấy phép OFL đi kèm từng family trong thư mục fonts. Không sửa file font. Nguồn: [Nunito Sans](https://fonts.google.com/specimen/Nunito+Sans), [Geologica](https://fonts.google.com/specimen/Geologica), [Inter](https://fonts.google.com/specimen/Inter).

Màu dùng đủ 19 vai trò của preset Reading. Thanh điều khiển so sánh dùng font hệ thống cố định; phần giao diện mẫu đổi theo font được chọn. Font được nạp và kiểm bốn weight trước khi thông báo đã tải đủ. Nếu tải thất bại, trang báo cần tải lại trước khi so sánh.

Kiểm: mở desktop/mobile, xác nhận font thực dùng và ký tự tiếng Việt, ba bản cùng nội dung/style ngoài font, đổi đủ ba ngữ cảnh, đổi cách xem/font/cỡ chữ, thử gõ/chọn/lưu/xóa, tải lại và link có tham số. Thay đổi chỉ trong thư mục này, không sửa CSS dùng chung hoặc hành trình của sản phẩm đang chạy.
